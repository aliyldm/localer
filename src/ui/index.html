Bağlantı ayarları

Varsayılan topluluk sunucusunu veya kendi EasyTier sunucunu kullanabilirsin. Özel sunucuda arkadaşlarına tam davet bağlantısını gönder.

Nasıl bağlanırım?

Oyun: Sunucuyu açan kişinin sanal IP adresini ve oyun portunu, oyunun doğrudan bağlantı alanına yaz.

Yerel web servisi: Servisi 0.0.0.0 üzerinde dinlet. Arkadaşların http://sanal-IP:port adresini açsın.

Cihaz görünüyor ama servis açılmıyorsa: Windows güvenlik duvarında servisi çalıştıran uygulamaya veya gereken TCP/UDP portuna gelen bağlantı izni ver. İzni mümkünse odanın sanal ağıyla sınırla. Localer’ın yönetici izni, diğer uygulamaların servis portlarını açmaz; güvenlik duvarını kapatmana gerek yok.

Kodu bilenler odaya girebilir. Bu sürümde kişi çıkarma yok; gerektiğinde yeni oda aç. Otomatik LAN keşfi her oyunda çalışmayabilir. İnternet çıkışınız ortak olmaz.
